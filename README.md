# FactoryFlow MX

Plataforma industrial de ingeniería de datos para controlar y analizar la
producción bajo pedido de una fábrica con múltiples estaciones de trabajo.

## Problema que resuelve

FactoryFlow MX integra eventos generados mediante códigos QR, archivos batch,
sistemas operativos de producción y telemetría en tiempo real para proporcionar:

- Trazabilidad por pedido, lote y pieza.
- Visibilidad del estado de cada estación.
- Detección de retrasos, defectos y datos inconsistentes.
- Medición de tiempos de ciclo y productividad.
- Alertas operativas y de calidad.
- Analítica industrial con control de costos.

## Proyectos del portafolio

1. Batch Integration Hub.
2. Industrial Event Streaming.
3. Manufacturing Data Warehouse.
4. Data Quality & Observability.
5. Composer Orchestration.
6. Manufacturing Control Tower.
